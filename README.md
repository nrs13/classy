# Classy

A reduced demo of an internal project: a video goes in and a predicted brain response comes out. Certain features and data are omitted due to a confidentiality agreement.

https://classy.nrsharan.com

## Run

From `web`:

```bash
npm install
npm run dev
```

`npm test` runs the tests. `npm run build` makes the production build.

Vercel uses `web` as the project root. A push to `main` deploys the demo.
