# Yeo 2011 seven-network cortical parcellation

These are the official fsaverage5 surface annotations from the Thomas Yeo Lab
CBIG repository:

- `lh.Yeo2011_7Networks_N1000.annot`
- `rh.Yeo2011_7Networks_N1000.annot`

Source commit: `6c3d48f3063516baa64c15f704df1ffc63efdcfd`

Source directory:
https://github.com/ThomasYeoLab/CBIG/tree/6c3d48f3063516baa64c15f704df1ffc63efdcfd/stable_projects/brain_parcellation/Yeo2011_fcMRI_clustering/1000subjects_reference/Yeo_JNeurophysiol11_SplitLabels/fsaverage5/label

SHA-256:

- left: `4d2ea20fa33afa722d35884d27b3577486d8d7e15520d7d23efdd84956139190`
- right: `53fa768b6c33a3bc8fb5b147d18049684514fcd07e2cbacceeca17cfc21d9e9b`

Each annotation contains 10,242 vertices. Labels are exported left hemisphere
first, then right hemisphere, matching the project's fsaverage5 mesh and TRIBE
activation ordering. Label 0 is the FreeSurfer-defined medial wall and is
excluded from network statistics.
